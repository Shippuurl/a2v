一个菜单，接上所有模型。

a2v 把 codex、多个中转代理、模型目录和会话恢复收进终端里的一个界面。 键盘上下选模型，回车进 codex；p 换代理，r 接着上次聊。

$ curl -fsSL https://tool.kervein.club/a2v/install.sh | bash

Linux / macOS · amd64 / arm64 · 安装前自动校验 sha256

PS> irm https://tool.kervein.club/a2v/install.ps1 | iex

Windows 10/11 · PowerShell 5.1 或 7 · 装到 %LOCALAPPDATA%\a2v
内置中转 new.8w8.shop（不带 key），装上后粘自己的 API Key 即可

❯ models

模型菜单

只列当前 key 真正授权的模型，历史自动折叠；按 t 才展开。

❯ proxy

代理随切随用

多个中转并存，切代理自动注入 base_url 与环境变量，不再手改 config.toml。

❯ resume

会话恢复

直接读 ~/.codex/sessions，挑一条继续，并强制换回你选的模型。

❯ pin

目录固定

项目里放一个 .a2v.json，进目录就是那个模型，回车即开工。

常用命令

命令作用
a2v交互菜单：选模型 / 切代理 / 恢复会话
a2v sol按别名或 id 直接启动 codex
a2v run <model> -- <args>透传参数给 codex
a2v proxy use <id>切换当前代理（list / add / rm 同族）
a2v key <sk-...>写入 key，并同步 codex 的 auth.json
a2v sync按当前 key 拉取授权模型（--prune 清理历史）
a2v models rm <id>删除目录里的模型
a2v pin <model>把当前目录固定到某个模型（- 清除）
a2v doctor体检：codex、配置、代理连通性
a2v update从本站更新自身
